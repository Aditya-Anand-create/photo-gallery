# How to Submit (Celebrare assignment)

Deadline: 23 October 2026, 8:00 PM IST
Google Form: https://forms.gle/fBdouZ18ZnUEtxjdA

The code is done and verified. Three steps remain, and they must be done by you.

## Step 1 - Push the code to a public GitHub repo

1. Go to https://github.com/new
2. Repository name: photo-gallery (or anything you like)
3. Set it to PUBLIC. Do not add a README (the project already has one).
4. Create the repo. GitHub then shows a page with the exact commands to push an existing folder - copy those commands and run them inside the photo-gallery folder.
5. Open the repo link in a browser and check the files are visible.

## Step 2 - Record the 5-minute video

- Read WALKTHROUGH.md first and work through the code until you can explain each segment in your own words. Practice before recording.
- Record your screen: Windows - press Win + G. Mac - QuickTime > New Screen Recording. (The assignment PDF lists these same free options.)
- Cover all 5 segments: (1) app working - loading, search, favourite survives refresh; (2) useFetchPhotos; (3) the useReducer favourites code; (4) useCallback and useMemo in Gallery.jsx; (5) one thing that was genuinely difficult for you.
- Keep it around 5 minutes.
- Upload to YouTube as UNLISTED, or Google Drive with "anyone with the link can view". Open the link in an incognito window to confirm it plays.

## Step 3 - Fill the Google Form

Form link: https://forms.gle/fBdouZ18ZnUEtxjdA
It asks for:
1. Your GitHub repo link (from Step 1)
2. Your recording link (from Step 2)
3. One line describing the hardest part of the assignment. Write your own honest line - the same thing you picked for Segment 5 of the video works well here.

Submit before 8:00 PM IST on 23 October.

## If anything breaks

- npm install, then npm run dev to run locally; npm test runs the logic tests.
- The app needs internet access (photos come from picsum.photos).
